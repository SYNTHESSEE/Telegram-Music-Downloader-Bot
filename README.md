# 🎵 Telegram Music Downloader Bot

Бесплатный Telegram-бот для скачивания музыки и видео из популярных сервисов: **YouTube**, **YouTube Music**, **Яндекс Музыка** и **Pinterest**. Бот принимает ссылку, извлекает медиаконтент в высоком качестве и отправляет его пользователю прямо в чат.

---

## ✨ Возможности

- 🎬 **YouTube / YouTube Music**  
  Скачивание аудио в формате MP3 (битрейт 192 kbps) через `yt-dlp` с обходом большинства ограничений.

- 🔴 **Яндекс Музыка**  
  Извлечение метаданных трека (исполнитель, название) с помощью публичного API или парсинга HTML, затем автоматический поиск оригинала на YouTube и скачивание аудио.

- 📌 **Pinterest**  
  Скачивание видеороликов (MP4) по прямым ссылкам или коротким `pin.it`.

- 📊 **Прогресс-бар и анимация**  
  Во время загрузки отображается статусное сообщение со спиннером и прогрессом в реальном времени.

- 🧹 **Автоочистка**  
  После успешной отправки файла бот удаляет его с сервера, экономя дисковое пространство.

- 🛠 **Гибкая настройка**  
  Поддержка SOCKS5-прокси, кастомных заголовков, выбор клиентов YouTube для стабильной работы.

## 🧰 Требования

- Python **3.9+**
- Установленный [FFmpeg](https://ffmpeg.org/) (или используйте встроенные бинарники в папке `ffmpeg/bin`)
- Доступ к прокси-серверу SOCKS5 (по умолчанию `socks5://127.0.0.1:10808`) для работы с YouTube
- Токен Telegram-бота (получить у [@BotFather](https://t.me/BotFather))

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/telegram-music-downloader-bot.git
cd telegram-music-downloader-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

> Файл `requirements.txt` уже содержит все необходимые пакеты.  
> Если вы хотите автоматически пересоздать его на основе импортов, запустите вспомогательный скрипт `DownUP.py` (см. раздел «Дополнительные утилиты»).

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```ini
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
DOWNLOAD_DIR=downloads
```

- `TELEGRAM_BOT_TOKEN` — обязательный параметр.  
- `DOWNLOAD_DIR` — папка для временного хранения загруженных файлов (по умолчанию `downloads`).

### 4. Настройка прокси

В файлах `bot.py` и `extractors/youtube.py` прописан SOCKS5-прокси:

```python
PROXY_URL = "socks5://127.0.0.1:10808"
```

Если у вас другой адрес прокси, измените его в обоих местах.  
Для работы с YouTube прокси **обязателен** (из-за географических ограничений и защиты от ботов).

### 5. Запуск бота

```bash
python bot.py
```

После запуска бот удалит вебхук и начнёт опрос обновлений (long polling).

## 📝 Использование

1. Найдите бота в Telegram по имени, которое вы задали при создании.  
2. Отправьте команду `/start`, чтобы увидеть приветственное сообщение.  
3. Отправьте ссылку на трек или видео. Поддерживаются:
   - `https://www.youtube.com/watch?v=...`
   - `https://youtu.be/...`
   - `https://music.youtube.com/watch?v=...`
   - `https://music.yandex.ru/track/...` или `https://music.yandex.ru/album/.../track/...`
   - `https://www.pinterest.com/pin/...` или `https://pin.it/...`
4. Дождитесь завершения загрузки — бот отправит медиафайл с подписью.

Примеры:

```
🎵 https://www.youtube.com/watch?v=dQw4w9WgXcQ
🔴 https://music.yandex.ru/track/1094819
📌 https://pin.it/7lKkV9A
```

## ⚙️ Дополнительные утилиты

### `DownUP.py` — автоопределение зависимостей

Сканирует все `.py` файлы проекта, находит импорты внешних пакетов, фильтрует стандартную библиотеку и локальные модули, затем создаёт/обновляет `requirements.txt` и устанавливает недостающие пакеты через `pip`.

Запуск:

```bash
python DownUP.py
```

### `9999.py` — генератор отчёта о проекте

Проходит по всем файлам и папкам (исключая скрытые и `.json`), создаёт `project_analysis.txt` с деревом проекта и полным содержимым исходников. Полезно для быстрого просмотра кода или отправки его третьим лицам.

Запуск:

```bash
python 9999.py
```

### `utils/audio_processor.py`

Содержит вспомогательные методы для работы с аудиофайлами:
- `compress_to_192()` — понижение битрейта MP3 до 192 kbps.
- `split_audio()` — нарезка аудио на части для обхода лимита Telegram (до 49 МБ).  
В текущей версии бота эти функции не используются напрямую, но могут быть легко интегрированы при необходимости.

## 📌 Примечания и ограничения

- **Прокси** — обязателен для YouTube. Если ваш сервер находится в регионе, где YouTube доступен без ограничений, вы можете убрать настройку `'proxy'` в `youtube.py` и `PROXY_URL` в `bot.py`.  
- **FFmpeg** — должен быть доступен в системе или лежать в `ffmpeg/bin`. В `youtube.py` также есть попытка использовать `static_ffmpeg` (если установлен).  
- **Яндекс Музыка** — бот пока не скачивает напрямую с Яндекс.Музыки из-за защиты; он извлекает название трека и исполнителя, а затем ищет это на YouTube. Качество зависит от найденного оригинала.  
- **Telegram API** — если файл превышает лимит (50 МБ для ботов), отправка может не сработать. В текущей реализации не предусмотрена автоматическая нарезка, но её можно добавить через `audio_processor`.  
- **Безопасность** — не передавайте бота в публичный доступ без ограничений (например, по ID пользователей), чтобы избежать злоупотреблений.
